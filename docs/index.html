このマインクラフトサーバーはこれからもずっと続けます。

開発サーバーでは、クリエイティブで建築の練習をしたり、他の人が作った建築を見ることができます。

少人数で遊んでいるので、初めての方や、久しぶりにマインクラフトで遊びたい方も参加しやすいと思います。

友達を呼んで一緒にサバイバルをするのもいいかもしれませんね！

初めての人でも安心に、

はじめて参加する人でも安心して遊べるように、資源サーバーを用意しています。

          サーバーのコンパスの使い方

          サバイバルサーバーに入るとインベントリーの一番右にコンパスを入手できます。

          こちらのコンパスではサーバーで使える便利な機能がたくさんあります！！

          スキル（鉄剣）

          このスキルでは、プレイヤーがブロックを壊す、農業をする、モブを倒すなどいろいろなアクションを起こすことによってレベルをあげることができます。またたくさんのスキルがあり、それぞれに特殊能力などもあるので、楽しみの１つです。

          スキルについて詳しく見る

          ショップ（チェスト）

          こちらはこのサーバーでも一番のメイン機能といっても過言ではありません！いくつかのアイテムを簡単に購入したりすることができます。

          商品一覧を見る

          アイテムを売る（ホッパー）

          こちらでは上で紹介したショップで商品を購入するためのお金を貯めることができます。すべてのアイテムを売れるというわけではありませんが、ショップに乗っているものはたいてい売ることができます。また商品の値段を確かめたいなどがあれば、商品一覧を見てください。

          土地保護（草ブロック）

          この機能を使えばあなたが立てた建築などを安全に保護することができます。

          保護について詳しく見る

          プレイヤーにテレポート（ダイヤモンド）

          この機能はほかのプレイヤーなどと集合するときに便利な機能です。また通称TPAとも呼びます。こちらを使うことによって好きなプレイヤーの所に許可がある限り、どこでも手レポートすることができます。また、この機能は同じディメンションにいるプレイヤーにしか使えないのでご注意ください。

          TPAについて詳しく見る

          資源サバにアイテムを送る（エンダーパール）

          こちらをクリックすると資源サバにアイテムを送れるサーバーのエンダーチェストのようなものが開くことができます。こちらを使うことによって資源サバにアイテムを送ることができます。

          この機能について詳しく見る

          毎日報酬（金リンゴ）

          毎日報酬です。ログインすることによって、エンチャント金リンゴを毎日１づつもらうことができます。ぜひたくさんログインしてみましょう！！

          家に帰る（岩盤）

          この機能は自分の家に簡単に手レポートすることができます。デフォルトでは、１つしか家を設定できませんが、ランクを購入することによって家の数を増やすことができます。

          ノーマルランク : 1個

          + ランク : 3個

          U ランク : 4個
